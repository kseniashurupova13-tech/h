# Movie Library (Личная кинотека)
**Автор:** [Шурупова Ксения]

## Описание
Приложение для хранения информации о просмотренных фильмах. Позволяет вести список, указывать жанр, год и личный рейтинг. Данные автоматически сохраняются в формате JSON.

## Функционал
- Добавление фильмов через удобную форму.
- Валидация: год должен быть числом, рейтинг в диапазоне от 0 до 10.
- Фильтрация списка по жанру и году выпуска.
- Хранение данных в файле `movies.json`.

## Примеры использования (Тесты)
1. **Добавление:** Введите "Интерстеллар", "Фантастика", "2014", "9.5". Нажмите добавить — фильм появится в таблице.
2. **Валидация:** Попробуйте ввести в рейтинг "12" или в год "текст" — программа выдаст ошибку.
3. **Фильтрация:** Введите в поле фильтра по жанру "Драма" — в таблице останутся только драмы.
